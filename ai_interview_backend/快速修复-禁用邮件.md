# 快速修复方案：暂时禁用邮件发送

如果你想快速测试注册功能而不需要实际发送邮件，可以按照以下步骤操作：

## 方案 1：使用控制台邮件后端（推荐用于开发）

修改 `.env` 文件中的 `EMAIL_BACKEND`：

```
# 将这行：
EMAIL_BACKEND=django.core.mail.backends.smtp.EmailBackend

# 改为：
EMAIL_BACKEND=django.core.mail.backends.console.EmailBackend
```

这样验证码会直接打印在 Django 服务器的控制台中，你可以从那里复制验证码来测试。

## 方案 2：查看 Django 服务器日志

当前配置下，验证码应该会打印在服务器控制台。查看 Django 服务器的输出，应该能看到类似这样的信息：

```
成功发送验证码 123456 到 user@example.com
```

## 方案 3：检查邮件发送错误

如果你想使用真实的邮件发送，请：

1. 确保 Django 服务器已重启
2. 查看服务器控制台的错误信息
3. 确认 QQ 邮箱的授权码是否正确
4. 确认网络连接正常

## 当前问题

发送验证码返回 500 错误，这通常意味着：
- SMTP 连接失败
- 授权码不正确
- 网络问题
- 或者 Django 服务器没有重启以加载新配置

请查看 Django 服务器控制台的完整错误信息以确定具体原因。
