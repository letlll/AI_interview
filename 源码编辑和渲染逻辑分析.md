## 🐛 核心问题分析

### 问题 1: 数据结构完全不匹配

#### 字段名不一致
| AI 返回 | 前端期望 | 状态 |
|---------|---------|------|
| `coreAbilities` | `skills` | ❌ 不匹配 |
| `projectExperience` | `projects` | ❌ 不匹配 |
| 无 `basicInfo` | `basicInfo` | ❌ 缺失 |
| `education.courses` (对象) | `education` (数组) | ❌ 类型不匹配 |

#### 数据类型不一致
```typescript
// AI 返回
skills: {
  coreTechStack: {
    frontend: [...],
    android: [...]
  }
}

// 前端期望
skills: ["Vue.js", "React", ...]  // 简单数组
```

### 问题 2: 渲染逻辑错误

#### ResumePreviewPanel.vue 的渲染条件

```vue
<!-- 专业技能 -->
<div v-if="resumeData.skills?.length" class="resume-section">
  <!-- 这里期望 skills 是数组 -->
  <el-tag v-for="(skill, index) in resumeData.skills">
    {{ skill }}
  </el-tag>
</div>
```

**问题：**
- `resumeData.skills?.length` 检查的是数组的 `length`
- 但实际 `skills` 是一个对象：`{ coreTechStack: {...}, devTools: [...], ... }`
- 对象没有 `length` 属性（除非是数组）
- 所以 `v-if` 条件为 `false`，不会渲染

#### 教育背景渲染

```vue
<!-- 教育背景 -->
<div v-if="resumeData.education?.length" class="resume-section">
  <!-- 期望 education 是数组 -->
  <div v-for="(edu, index) in resumeData.education">
    <strong>{{ edu.school }}</strong>
    <span>{{ edu.duration }}</span>
    <div>{{ edu.major }} · {{ edu.degree }}</div>
  </div>
</div>
```

**问题：**
- 期望 `education` 是数组：`[{ school: "...", major: "...", ... }]`
- 实际 `education` 是对象：`{ courses: [...] }`
- `education.length` 为 `undefined`
- 即使渲染，也无法访问 `edu.school`、`edu.major` 等属性

### 问题 3: 源码编辑逻辑问题

#### 当前实现

```typescript
// ResumePreviewPanel.vue

// 监听 resumeData 变化，更新源码
watch(() => props.resumeData, (newData) => {
  if (newData && editMode.value === 'source') {
    sourceCode.value = JSON.stringify(newData, null, 2);
  }
}, { immediate: true });

// 监听编辑模式切换
watch(editMode, (newMode) => {
  if (newMode === 'source' && props.resumeData) {
    sourceCode.value = JSON.stringify(props.resumeData, null, 2);
  }
});

// 保存源码修改
const handleSourceCodeChange = () => {
  try {
    const parsed = JSON.parse(sourceCode.value);
    // 触发整个简历数据的更新
    emit('field-change', '', parsed);
    ElMessage.success('源码已更新');
  } catch (error) {
    ElMessage.error('JSON 格式错误，请检查');
  }

```

#### 问题分析

**问题 3.1: 初始化时机错误**
```typescript
watch(() => props.resumeData, (newData) => {
  if (newData && editMode.value === 'source') {
    sourceCode.value = JSON.stringify(newData, null, 2);
  }
}, { immediate: true });
```

- `immediate: true` 会在组件挂载时立即执行
- 但此时 `editMode.value === 'preview'`（默认值）
- 所以条件 `editMode.value === 'source'` 为 `false`
- **结果：源码不会初始化**

**问题 3.2: 切换到源码模式时才初始化**
```typescript
watch(editMode, (newMode) => {
  if (newMode === 'source' && props.resumeData) {
    sourceCode.value = JSON.stringify(props.resumeData, null, 2);
  }
});
```

- 只有切换到源码模式时才初始化
- 如果用户直接在预览模式下，源码永远是空的
- **这是正确的行为**，但与第一个 watch 冲突

**问题 3.3: 父组件处理错误**
```typescript
// ResumeGeneratorNew.vue
const handleFieldChange = (path: string, value: string) => {
  lastEditedField.value = path;
  console.log(`字段修改: ${path} = ${value}`);
  
  // 保存版本
  if (resumeData.value) {
    addVersion(
      resumeData.value as AIResumeData,
      `手动修改 ${path}`,
      [{ action: 'update', path, value }]
    );
  }
}
```

**问题：**
- 当 `path === ''` 时（源码模式），`value` 是整个对象
- 但这里没有更新 `resumeData.value`
- 只是保存了版本，但数据没有变化
- **结果：源码编辑后，数据不会更新**

### 3. 渲染逻辑修正

#### 方案 A: 创建适配器组件

```vue
<!-- ResumeRenderer.vue -->
<template>
  <div class="resume-render">
    <!-- 基本信息 -->
    <BasicInfoSection :data="adaptedData.basicInfo" />
    
    <!-- 专业技能 -->
    <SkillsSection :data="adaptedData.skills" />
    
    <!-- 工作经历 -->
    <WorkExperienceSection :data="adaptedData.workExperience" />
    
    <!-- 项目经验 -->
    <ProjectsSection :data="adaptedData.projects" />
    
    <!-- 教育背景 -->
    <EducationSection :data="adaptedData.education" />
  </div>
</template>

<script setup>
import { computed } from 'vue';

const props = defineProps<{
  resumeData: any;
}>();

// 数据适配器
const adaptedData = computed(() => {
  const data = props.resumeData || {};
  
  return {
    basicInfo: adaptBasicInfo(data),
    skills: adaptSkills(data),
    workExperience: adaptWorkExperience(data),
    projects: adaptProjects(data),
    education: adaptEducation(data)
  };
});

function adaptBasicInfo(data: any) {
  return data.basicInfo || {
    name: '未填写',
    phone: '',
    email: '',
    location: ''
  };
}

function adaptSkills(data: any) {
  const skills = data.skills;
  
  // 如果是数组，直接返回
  if (Array.isArray(skills)) {
    return skills;
  }
  
  // 如果是对象，展平为数组
  if (typeof skills === 'object' && skills !== null) {
    const result = [];
    
    // 递归提取所有技能
    function extractSkills(obj: any) {
      for (const key in obj) {
        const value = obj[key];
        if (Array.isArray(value)) {
          result.push(...value);
        } else if (typeof value === 'object') {
          extractSkills(value);
        } else if (typeof value === 'string') {
          result.push(value);
        }
      }
    }
    
    extractSkills(skills);
    return result;
  }
  
  return [];
}

function adaptWorkExperience(data: any) {
  return data.workExperience || [];
}

function adaptProjects(data: any) {
  // 支持 projects 或 projectExperience
  return data.projects || data.projectExperience || [];
}

function adaptEducation(data: any) {
  const education = data.education;
  
  // 如果是数组，直接返回
  if (Array.isArray(education)) {
    return education;
  }
  
  // 如果是对象（如 { courses: [...] }），转换为数组
  if (typeof education === 'object' && education !== null) {
    // 如果有 courses 字段，创建一个教育项
    if (education.courses && Array.isArray(education.courses)) {
      return [{
        school: '课程列表',
        major: education.courses.join('、'),
        degree: '',
        duration: ''
      }];
    }
  }
  
  return [];
}
</script>
```

## 💡 总结

### 核心问题
1. **数据结构不匹配** - AI 返回的结构与前端期望不一致
2. **源码编辑不生效** - `handleFieldChange` 没有更新 `resumeData`
3. **渲染条件错误** - `v-if` 检查数组 `length`，但实际是对象

### 解决方案
1. **添加数据适配层** - 在渲染前转换数据格式
2. **修复源码编辑逻辑** - 正确处理 `path === ''` 的情况
3. **统一数据格式** - 修改 AI prompt 或后端格式化

### 最佳实践
- ✅ 使用 computed 进行数据适配
- ✅ 在一个地方处理数据转换
- ✅ 保持前后端数据格式一致
- ✅ 添加类型检查和容错逻辑
