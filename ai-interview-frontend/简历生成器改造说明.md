## 🎨 功能特性

### 左侧栏 - 模板选择

- **默认状态**：60px 宽，只显示图标
- **展开状态**：200px 宽，显示图标 + 名称 + 描述
- **交互方式**：点击顶部按钮展开/收起
- **模板列表**：
  - 📄 经典模板（适合传统行业）
  - 📋 现代模板（适合互联网）
  - 📝 简约模板（适合设计师）
  - 📑 专业模板（适合金融业）
  - 📃 创意模板（适合创意岗）

### 中间栏 - AI 对话

- **消息列表**：显示用户和AI的对话历史
- **输入框**：支持多行输入，Ctrl+Enter 发送
- **快捷指令**：
  - 生成简历
  - 添加工作经历
  - 优化描述
  - 添加项目经验
- **流式输出**：AI回复逐字显示（待后端实现）
- **加载状态**：显示打字动画

### 右侧栏 - 实时预览

- **工具栏**：保存、导出按钮
- **实时渲染**：根据选择的模板动态渲染简历
- **内容区块**：
  - 基本信息（姓名、联系方式）
  - 专业技能（标签展示）
  - 工作经历（公司、职位、描述）
  - 项目经验（项目名、角色、描述）
  - 教育背景（学校、专业、学位）
- **空状态**：未生成内容时显示提示

## 🎯 使用方式

### 1. 访问页面


- 点击顶部或右侧的"保存"按钮保存到简历库
- 点击"导出"按钮导出为 PDF（待实现）

## 🔧 技术实现

### 数据流

```
用户输入 → handleUserMessage()
    ↓
调用 AI API (generateResumeFromChat)
    ↓
返回 AI 回复 + 简历数据
    ↓
更新 resumeData (响应式)
    ↓
右侧预览自动重新渲染
```

### 状态管理

```typescript
// 主容器状态
const selectedTemplate = ref('classic');  // 当前选择的模板
const resumeData = ref<ResumeData | null>(null);  // 简历数据
const sidebarWidth = ref('60px');  // 左侧栏宽度

// 简历数据结构
interface ResumeData {
  basicInfo?: {
    name?: string;
    phone?: string;
    email?: string;
    location?: string;
  };
  skills?: string[];
  workExperience?: WorkExperience[];
  projects?: Project[];
  education?: Education[];
}
```

### 组件通信

```
主容器 (ResumeGeneratorNew.vue)
    ├─> TemplateSidebar (v-model 双向绑定模板ID)
    ├─> AIChatPanel (emit message-sent 事件)
    └─> ResumePreviewPanel (props 传递数据)
```

