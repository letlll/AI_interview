# 📺 简历预览控制功能说明

## ✅ 已添加的功能

### 1. 顶部工具栏预览按钮

**位置：** 页面顶部右侧工具栏

**样式：**
```
┌─────────────────────────────────────────────────┐
│ AI 简历生成器    [👁 显示预览] | 保存 | 导出PDF │
└─────────────────────────────────────────────────┘
```

**功能：**
- 点击切换预览面板的显示/隐藏
- 按钮文字动态变化：
  - 显示预览时：`隐藏预览`（蓝色高亮）
  - 隐藏预览时：`显示预览`（灰色）

---

### 2. 三种控制方式

#### 方式 1：顶部按钮（推荐）
```
点击顶部工具栏的 [👁 显示预览/隐藏预览] 按钮
```
- ✅ 最直观
- ✅ 位置固定
- ✅ 有文字说明

#### 方式 2：边缘按钮
```
点击右侧边缘的 [<] 或 [>] 按钮
```
- ✅ 节省空间
- ✅ 靠近预览区
- ✅ 动画效果

#### 方式 3：键盘快捷键（未来可添加）
```
按 Ctrl+B 切换预览
```
- 🔄 待实现

## 🔧 技术实现

### 1. 按钮组件
```vue
<el-button 
  @click="togglePreview" 
  :type="isPreviewCollapsed ? 'default' : 'primary'"
  plain
>
  <el-icon><View /></el-icon>
  {{ isPreviewCollapsed ? '显示预览' : '隐藏预览' }}
</el-button>
```

### 2. 切换逻辑
```typescript
const togglePreview = () => {
  isPreviewCollapsed.value = !isPreviewCollapsed.value;
  
  if (isPreviewCollapsed.value) {
    ElMessage.info('已隐藏预览面板');
  } else {
    ElMessage.success('已显示预览面板');
  }
};
```

### 3. 样式控制
```scss
.content-grid {
  grid-template-columns: 1fr 1fr;
  transition: grid-template-columns 0.3s ease;
  
  &.preview-collapsed {
    grid-template-columns: 1fr 0;
  }
}
```

## 💬 常见问题

### Q1：为什么有两个按钮？
**A：** 提供两种控制方式：
- 顶部按钮：适合首次使用，更直观
- 边缘按钮：适合熟练用户，更快捷

### Q2：预览默认是显示还是隐藏？
**A：** 默认显示，方便用户实时查看简历生成效果

### Q3：移动端如何使用？
**A：** 移动端使用浮动按钮，点击后全屏显示预览

### Q4：可以记住我的偏好吗？
**A：** 暂不支持，每次刷新页面都会恢复默认状态（显示预览）
