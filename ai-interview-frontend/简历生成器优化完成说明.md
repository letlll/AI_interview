async function* streamAIResponse(prompt: string) {
  const response = await fetch('/api/v1/resumes/ai-stream/', {
    method: 'POST',
    body: JSON.stringify({ prompt })
  });
  
  const reader = response.body.getReader();

## 🎓 学习资源

### 关键概念

1. **增量更新 vs 完整替换**
   - 增量：只传递变化部分
   - 完整：每次传递全部数据

2. **意图识别 vs 关键词匹配**
   - 意图：理解用户真实需求
   - 关键词：简单模式匹配

3. **语义过滤 vs 时间过滤**
   - 语义：根据相关性选择历史
   - 时间：只保留最近的历史

### 参考实现

- **Cursor**：增量编辑 + 上下文压缩
- **Claude Artifacts**：实时预览 + 版本管理
- **Obsidian**：双模式编辑（预览/源码）
