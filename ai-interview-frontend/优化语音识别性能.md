# 优化语音识别性能和卡顿问题

## 问题分析

语音识别卡顿的可能原因：
1. **持续识别模式** (`continuous: true`) 导致频繁触发回调
2. **临时结果** (`interimResults: true`) 产生大量中间结果
3. **回调函数中的 DOM 操作**过于频繁
4. **浏览器语音识别 API 的性能限制**

## 优化方案

### 方案 1：添加防抖处理（推荐）

修改 `useSpeechRecognition.ts`：

```typescript
import { ref, onUnmounted } from 'vue';
import { ElMessage } from 'element-plus';

// 添加防抖函数
function debounce<T extends (...args: any[]) => any>(
  func: T,
  wait: number
): (...args: Parameters<T>) => void {
  let timeout: ReturnType<typeof setTimeout> | null = null;
  return function(...args: Parameters<T>) {
    if (timeout) clearTimeout(timeout);
    timeout = setTimeout(() => func(...args), wait);
  };
}

export function useSpeechRecognition(onResult: (transcript: string) => void) {
  const isSupported = 'SpeechRecognition' in window || 'webkitSpeechRecognition' in window;
  const SpeechRecognition = window.SpeechRecognition || window.webkitSpeechRecognition;
  
  const isListening = ref(false);
  const error = ref<string | null>(null);
  
  let recognition: any | null = null;
  let accumulatedTranscript = ''; // 累积识别结果

  if (isSupported) {
    recognition = new SpeechRecognition();
    recognition.continuous = true;
    recognition.interimResults = true;
    recognition.lang = 'zh-CN';
    recognition.maxAlternatives = 1; // 只返回最佳结果

    recognition.onstart = () => {
      isListening.value = true;
      error.value = null;
      accumulatedTranscript = '';
    };

    // 创建防抖的结果处理函数（300ms 延迟）
    const debouncedOnResult = debounce((transcript: string) => {
      if (transcript.trim()) {
        onResult(transcript);
        accumulatedTranscript = ''; // 清空累积
      }
    }, 300);

    recognition.onresult = (event: any) => {
      let finalTranscript = '';

      // 只处理最终结果，忽略临时结果以提升性能
      for (let i = event.resultIndex; i < event.results.length; ++i) {
        if (event.results[i].isFinal) {
          finalTranscript += event.results[i][0].transcript;
        }
      }
      
      if (finalTranscript) {
        accumulatedTranscript += finalTranscript;
        debouncedOnResult(accumulatedTranscript);
      }
    };

    recognition.onerror = (event: any) => {
      console.error('语音识别错误:', event.error);
      
      // 某些错误可以忽略
      if (event.error === 'no-speech' || event.error === 'aborted') {
        return;
      }
      
      error.value = `语音识别错误: ${event.error}`;
      ElMessage.error(error.value);
      isListening.value = false;
    };

    recognition.onend = () => {
      isListening.value = false;
      // 如果有未处理的累积文本，立即处理
      if (accumulatedTranscript.trim()) {
        onResult(accumulatedTranscript);
        accumulatedTranscript = '';
      }
    };
  }

  const start = () => {
    if (!isSupported) {
      ElMessage.warning('您的浏览器不支持语音识别功能。');
      return;
    }
    if (!isListening.value) {
      try {
        recognition.start();
      } catch (e) {
        console.error('启动语音识别失败:', e);
      }
    }
  };

  const stop = () => {
    if (isListening.value && recognition) {
      try {
        recognition.stop();
      } catch (e) {
        console.error('停止语音识别失败:', e);
      }
    }
  };

  onUnmounted(() => {
    stop();
  });

  return {
    isListening,
    isSupported,
    error,
    start,
    stop,
  };
}
```

### 方案 2：优化 DOM 更新

修改 `InterviewRoom.vue` 中的 `handleSpeechResult`：

```typescript
// 使用 requestAnimationFrame 批量更新 DOM
let pendingTranscript = '';
let rafId: number | null = null;

const handleSpeechResult = (transcript: string) => {
  pendingTranscript += transcript;
  
  if (rafId) return; // 如果已有待处理的更新，跳过
  
  rafId = requestAnimationFrame(() => {
    if (userAnswer.value.endsWith('</p>')) {
      userAnswer.value = userAnswer.value.slice(0, -4) + pendingTranscript + '</p>';
    } else {
      userAnswer.value += pendingTranscript;
    }
    pendingTranscript = '';
    rafId = null;
  });
};
```

### 方案 3：关闭临时结果（最简单）

如果不需要实时显示识别中的文本，可以关闭临时结果：

```typescript
recognition.interimResults = false; // 改为 false
```

这样只会在用户停顿时返回最终结果，大幅减少回调次数。

### 方案 4：使用分段识别

不使用持续模式，改为按需启动/停止：

```typescript
recognition.continuous = false; // 改为 false

// 在 onend 中自动重启（如果需要）
recognition.onend = () => {
  isListening.value = false;
  if (shouldContinue) { // 添加一个标志位控制
    setTimeout(() => recognition.start(), 100);
  }
};
```

## 其他优化建议

### 1. 限制识别时长

```typescript
let recognitionTimeout: ReturnType<typeof setTimeout> | null = null;

const start = () => {
  if (!isSupported || isListening.value) return;
  
  recognition.start();
  
  // 60秒后自动停止
  recognitionTimeout = setTimeout(() => {
    stop();
    ElMessage.info('语音识别已自动停止，请重新开始');
  }, 60000);
};

const stop = () => {
  if (recognitionTimeout) {
    clearTimeout(recognitionTimeout);
    recognitionTimeout = null;
  }
  if (isListening.value && recognition) {
    recognition.stop();
  }
};
```

### 2. 添加状态指示

```typescript
const recognitionStatus = ref<'idle' | 'listening' | 'processing'>('idle');

recognition.onstart = () => {
  recognitionStatus.value = 'listening';
};

recognition.onresult = () => {
  recognitionStatus.value = 'processing';
  setTimeout(() => {
    if (isListening.value) {
      recognitionStatus.value = 'listening';
    }
  }, 500);
};
```

### 3. 错误重试机制

```typescript
let retryCount = 0;
const MAX_RETRIES = 3;

recognition.onerror = (event: any) => {
  if (event.error === 'network' && retryCount < MAX_RETRIES) {
    retryCount++;
    setTimeout(() => {
      if (!isListening.value) {
        recognition.start();
      }
    }, 1000 * retryCount);
  }
};

recognition.onstart = () => {
  retryCount = 0; // 重置重试计数
};
```
