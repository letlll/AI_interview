# 🧪 UI 优化测试指南

## 快速测试步骤

### 1️⃣ 启动项目
```bash
cd ai-interview-frontend
npm run dev
```

访问：`http://localhost:5174/dashboard/generate-resume`

---

### 2️⃣ 测试滚动功能

#### 测试消息滚动
1. 在 AI 对话框输入："帮我生成一份前端工程师的简历"
2. 等待 AI 回复
3. 继续输入多条消息
4. **验证：** 消息列表应该可以滚动查看所有内容
5. **验证：** 滚动条宽度 8px，圆角，hover 时颜色变深

#### 测试预览滚动
1. 生成简历后，查看右侧预览区
2. 如果内容超出屏幕高度
3. **验证：** 预览区应该可以滚动
4. **验证：** 滚动条样式与消息区一致

---

### 3️⃣ 测试收缩功能

#### 收起预览
1. 找到右侧边缘的 `<` 按钮（中间位置）
2. 点击按钮
3. **验证：** 预览面板平滑收起（0.3s 动画）
4. **验证：** AI 对话区占满全屏
5. **验证：** 按钮变为 `>` 并移到右侧外边缘

#### 展开预览
1. 点击右侧的 `>` 按钮
2. **验证：** 预览面板平滑展开
3. **验证：** 恢复 50/50 分栏布局
4. **验证：** 按钮变为 `<` 并移回中间

---

### 4️⃣ 测试响应式

#### 桌面端（> 1280px）
1. 浏览器窗口全屏
2. **验证：** 左右各占 50%
3. **验证：** 收缩按钮在中间边缘

#### 中等屏幕（768px - 1280px）
1. 缩小浏览器窗口到 1000px 左右
2. **验证：** AI 对话 45%，预览 55%
3. **验证：** 收缩功能正常

#### 移动端（< 768px）
1. 打开浏览器开发者工具
2. 切换到移动设备模式（iPhone 12）
3. **验证：** 默认显示 AI 对话
4. **验证：** 右下角有圆形浮动按钮
5. 点击浮动按钮
6. **验证：** 全屏显示简历预览
7. 再次点击
8. **验证：** 返回 AI 对话

## 🐛 常见问题排查

### 问题 1：滚动条不显示
**可能原因：**
- 内容未溢出
- CSS 未正确加载
- min-height 未设置

**解决方案：**
1. 检查控制台是否有 CSS 错误
2. 检查元素高度是否正确
3. 强制刷新浏览器（Ctrl+Shift+R）

### 问题 2：收缩按钮不显示
**可能原因：**
- 图标未导入
- z-index 被覆盖
- 按钮被隐藏

**解决方案：**
1. 检查控制台是否有导入错误
2. 检查元素是否存在（F12 查看）
3. 检查 CSS 样式是否正确

### 问题 3：动画不流畅
**可能原因：**
- 浏览器性能问题
- transition 未设置
- GPU 加速未启用

**解决方案：**
1. 关闭其他标签页
2. 检查 transition 属性
3. 添加 `transform: translateZ(0)` 启用 GPU

### 问题 4：移动端布局错乱
**可能原因：**
- 媒体查询未触发
- viewport 未设置
- CSS 优先级问题

**解决方案：**
1. 检查 `<meta name="viewport">` 标签
2. 检查媒体查询断点
3. 使用 `!important` 强制样式
